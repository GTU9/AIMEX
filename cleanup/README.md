# AIMEX cleanup workspace

이 디렉터리는 전 저장소 AI-slop 정리의 범위, 변경 이유, 후속 이슈를 기록한다.

- [변경 기록](./CHANGELOG.md)
- [후속 이슈 목록](./issues/README.md)

## 적용 원칙

1. 저장소 전체를 조사하되 참조가 없고 동작 영향이 없는 코드만 즉시 삭제한다.
2. 인증, 데이터베이스, 외부 서비스 fallback처럼 계약을 바꾸는 항목은 이슈로 분리한다.
3. 정리 전후에 회귀 테스트, Python 컴파일, TypeScript 검사를 실행한다.
4. 새 추상화나 의존성을 추가하지 않는다.

## 이번 범위

- 사용되지 않는 Python 아키텍처 골격 및 응답 추상화
- 독립 예제·디버그 파일
- 참조되지 않는 프런트엔드 디버그/가이드 컴포넌트
- 데이터 매핑의 기존 동작을 보호하는 회귀 테스트
- 즉시 변경하기 위험한 fallback·보안·DB·설정 문제의 이슈화
